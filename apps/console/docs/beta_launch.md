# Beta Launch Checklist

- Launch scope: Australia, one program profile, one evidence category, one artifact profile, and named design-partner organizations.
- Replay seeded fixture flow from source intake through recorded reliance.
- Confirm profile/version, role matrix, artifact profile, and support owner before enabling an organization.
- Track intake-to-normalization time, gap closure time, review turnaround, determination publication rate, artifact issuance rate, verifier placeholder status, webhook delivery health, and support tickets per project.
- Convert repeated manual work into explicit backlog items.
- Do not use undocumented production-only data edits or production-only patches.
