# AgEvidence Evaluations

This directory is reserved for fixture parity checks and adapter-substitution evaluations.

The first acceptance target is not model accuracy. It is preservation of source references, explicit gap reporting, and stable normalized output contracts.

Global portability evaluations should use one synthetic intervention evidence graph across Australia, Canada, Japan, New Zealand, Ireland/EU, and Brazil. Expected behavior:

- underlying evidence receipt commitments stay identical;
- adapter commitments and country determinations differ;
- artifact manifests differ by profile;
- the same offline verifier contract applies everywhere.
