# AgEvidence Country Adapter Packs

Country adapter packs are declarative policy data. They map local terminology, method scope, evidence requirements, claim policies, verification profiles, data policies, and artifact profiles onto the stable global AgEvidence vocabulary.

Do not encode national methodology rules in Rails controllers, ERB templates, Python prompts, JavaScript, model adapters, or generic Rust crates. Add or supersede YAML packs here, then append new country determinations against the existing evidence graph.

Each `adapter.yml` should conform to `specs/agevidence/schemas/athian.country_adapter_manifest.v1.json`.
