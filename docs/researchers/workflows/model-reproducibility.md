# Model Reproducibility

Research model runs should preserve enough context for another researcher to
reconstruct the computation.

Minimum fields:

- model ID and version
- input commitments
- implementation digest or published procedure
- parameters
- software/runtime environment
- outputs
- limitations

The intercontinental prediction case study uses these fields to represent the
Niu et al. global and regional methane-model architecture without claiming that
the private consolidated dataset is present.
