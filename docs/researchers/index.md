# AgEvidence for Researchers

```bash
pip install agevidence
```

Turn experimental measurements, interventions, statistical analyses, and
scientific claims into reconstructable evidence objects. Start with real
published livestock research from UC Davis.

## Start Here

- [10-minute researcher quickstart](quickstart.md)
- [Reconstruct a published experiment](workflows/experiment-to-evidence.md)
- [Understand the evidence model](concepts/source-records.md)

Researchers do not need to start with commercial console vocabulary. The
researcher branch treats AgEvidence as a local evidence-object toolkit: source
records, observations, interventions, operational events, model runs, and
example scientific statements are assembled into reproducible bundles.

## Real Datasets Used In This Guide

- Roque et al. 2021, PLOS ONE: public original XLSX supporting dataset.
- Ramirez-Agudelo and Kebreab 2024: public Zenodo v2 methane database XLSX.
- Published GreenFeed measurement protocols.
- Published Akter et al. 2025 grape-pomace experimental design and methods.
- Published Meo-Filho et al. 2024 grazing-beef field-study summaries.
- Published Niu et al. 2018 intercontinental methane-model architecture.
- UC Davis RationSmart national-feed-database architecture.

## Notebook Progression

- Notebook 01: Roque 2021 original data.
- Notebook 02: Kebreab methane database.
- Notebook 03: GreenFeed provenance.
- Notebook 04: Grape pomace Latin square.
- Notebook 05: Intercontinental prediction.
- Notebook 06: Feed to methane.

The first two paths execute from public workbooks. Later paths are case-study
reconstructions until row-level public datasets are available.
