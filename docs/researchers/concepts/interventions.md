# Interventions

An intervention event records something physically applied or changed.

In the Roque tutorial, treatment assignments are reconstructed as
`InterventionEvent`-shaped records:

- Control
- 0.25% organic-matter Asparagopsis taxiformis inclusion
- 0.50% organic-matter Asparagopsis taxiformis inclusion

In the grape-pomace case study, the same idea represents control, 10% grape
pomace, and 15% grape pomace treatments in a published 3 x 3 Latin-square
design. Where exact cow-period rows are not public, the example records the
public-data limitation instead of inventing rows.
