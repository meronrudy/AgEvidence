# Model Runs

A model run records a computation that produces a derived result.

Research model runs preserve:

- model identity and version
- input commitments
- parameters
- execution environment
- outputs
- limitations

The first tutorial uses a small treatment-summary model over the Roque workbook.
The second tutorial uses a sample-size calculation over an analysis population
after variability transformation and exclusion decisions.

For published studies where raw rows are unavailable, a model run can still
preserve the reported statistical lineage, such as SAS 9.4, PROC GLIMMIX,
fixed effects, random effects, preprocessing, and output shape.
