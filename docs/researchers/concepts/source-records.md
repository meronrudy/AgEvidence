# Source Records

A source record is the original material being relied on before transformation:
a workbook, instrument export, lab report, published table, or DOI-addressed
dataset.

In the researcher examples, public workbooks become `SourceRecord`-shaped
objects with:

- source system
- record ID or DOI
- controlled URI
- checksum commitment
- license and distribution metadata

The Roque tutorial registers the PLOS S1 workbook as one source record. The
Ramirez-Agudelo/Kebreab tutorial registers the Zenodo v2 workbook and preserves
its DOI, SHA-256, and MD5.
